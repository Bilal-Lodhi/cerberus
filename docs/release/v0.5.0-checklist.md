## 3. What must never happen in the publication step

- **No `npm publish`.** Every workspace package is `private`, and `npm run verify:packages` fails if
  one is not.
- **No container image push.** The harness builds and runs the image; it never pushes it, and
  `scripts/release/publish-guard.json` rejects a publishing command in the harness directory.
- **No tag other than the intended annotated tag**, and no re-tagging of `v0.1.0`–`v0.4.0`.
- **No history rewrite.** The eleven historical synthetic co-author trailers stay exactly as they
  are; the attribution guard is prospective and only checks the commits being introduced.
- **No "stable" or "latest" marking.** Every release so far is a pre-release, and this one is too.
